# CX Solutions

CX Solutions is an expansion mod for the game **Software Inc.** The primary goal of this mod is to introduce a variety of new software types, and potentially real-world hardware types, into the game, expanding the scope and depth of gameplay.

## Overview
This mod aims to create a more immersive and comprehensive tech industry simulation by adding realistic product categories that players can develop, manufacture, and sell.

## Development
This mod is built from the ground up to ensure balanced gameplay, drawing inspiration and lessons from earlier legacy implementations to provide a stable and engaging experience for players.
